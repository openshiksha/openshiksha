## B. Why This Matters

Session 1 today completed the full core educational data layer (questions, assignments, submissions). Two things are now the most urgent next steps:

1. **CI is completely broken** — The GitHub Actions workflow still runs Python 2.7 with old action versions. Every PR merged from now on has zero CI coverage. This undermines reviewer confidence and will silently break things. Fix this now before another PR is merged.

2. **Analytics is the platform's differentiator** — Once submissions exist, the platform can compute proficiency. The proficiency algorithm (`score = (0.7 × rate) + (0.3 × percentile)`) is the core of what makes OpenShiksha more than a simple quiz tool. Without it, the platform is a loop with no feedback: students answer questions but never see progress.

3. **Grading must be automatic** — Submissions are stored but never scored without the Celery grading task. The student experience won't work end-to-end without it.

**`StudentProficiency`** — per-student per-tag proficiency within a SubjectRoom
```python
class StudentProficiency(models.Model):
    """
    Tracks a student's proficiency in a specific QuestionTag within a SubjectRoom.

    Score = (0.7 × rate) + (0.3 × percentile)
    - rate: student's average mark in this tag
    - percentile: how they rank vs classmates in the same tag
    """
    student = models.ForeignKey(
        'core.User', on_delete=models.CASCADE, related_name='proficiencies'
    )
    question_tag = models.ForeignKey(
        'core.QuestionTag', on_delete=models.CASCADE, related_name='student_proficiencies'
    )
    subject_room = models.ForeignKey(
        'core.SubjectRoom', on_delete=models.CASCADE, related_name='student_proficiencies'
    )
    # Accumulated state
    total_marks = models.FloatField(default=0.0, validators=[MinValueValidator(0.0)])
    tick_count = models.PositiveIntegerField(default=0)
    rate = models.FloatField(default=0.0, validators=FRACTION_VALIDATOR,
        help_text='Average mark in this tag (total_marks / tick_count)')
    # Updated when percentile is recalculated
    percentile = models.FloatField(default=0.0, validators=FRACTION_VALIDATOR)
    score = models.FloatField(default=0.0, validators=FRACTION_VALIDATOR,
        help_text='(0.7 × rate) + (0.3 × percentile)')
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        unique_together = [['student', 'question_tag', 'subject_room']]
        indexes = [
            models.Index(fields=['subject_room', 'question_tag']),
            models.Index(fields=['student', 'score']),
        ]

    def apply_tick(self, tick: Tick) -> None:
        """Update rate from a new tick. Does NOT recalculate percentile/score."""
        self.tick_count += 1
        self.total_marks += tick.mark
        self.rate = self.total_marks / self.tick_count
        self.save(update_fields=['tick_count', 'total_marks', 'rate', 'updated_at'])

    def recalculate_score(self, percentile: float) -> None:
        """Set percentile and recompute final score."""
        self.percentile = percentile
        self.score = (0.7 * self.rate) + (0.3 * self.percentile)
        self.save(update_fields=['percentile', 'score', 'updated_at'])
```
- **Legacy kept**: student, questiontag, subjectroom FKs, rate/percentile/score fields, `(0.7 * rate) + (0.3 * percentile)` formula, total/ticks accumulators
- **Improved**: `update_fields` in `save()` to avoid full row writes; `updated_at` for cache invalidation; field renamed `questiontag` → `question_tag` for PEP8

```python
class SubjectRoomQuestionMistake(models.Model):
    """
    Aggregates marks lost for a specific question across a SubjectRoom.
    Teachers can use this to identify which questions caused the most difficulty.
    """
    subject_room = models.ForeignKey(
        'core.SubjectRoom', on_delete=models.CASCADE, related_name='question_mistakes'
    )
    question = models.ForeignKey(
        'core.Question', on_delete=models.CASCADE, related_name='question_mistakes'
    )
    regression = models.FloatField(
        default=0.0, validators=[MinValueValidator(0.0)],
        help_text='Cumulative marks lost (absolute, not fraction)'
    )
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        unique_together = [['subject_room', 'question']]

    def apply_tick(self, tick: Tick, num_subparts: int) -> None:
        self.regression += (1.0 - tick.mark) / num_subparts
        self.save(update_fields=['regression', 'updated_at'])
```

- **Improved**: `num_subparts` passed in instead of calling `question.get_num_subparts()` on every tick (avoids N+1 query); `updated_at` for ordering "recent mistakes"

### Priority 3: Grading Celery Task

**File**: `backend/openshiksha/apps/core/tasks.py` (create new)

```python
"""
Celery tasks for grading submissions and updating analytics.
"""
from celery import shared_task
from django.utils import timezone
import logging

logger = logging.getLogger(__name__)


@shared_task(bind=True, max_retries=3)
def grade_submission(self, submission_id: int) -> dict:
    """
    Grade a submission after student submits answers.

    Steps:
    1. Load submission + assignment + problem_set + questions
    2. For each question subpart, compare submission answer to correct_answer
    3. Create Tick records for each subpart
    4. Compute submission.score and submission.completion
    5. Save submission
    6. Update Assignment aggregates (average_score, completion_rate)
    7. Queue proficiency update task

    Returns dict with grading summary.
    """
    from openshiksha.apps.core.models import Submission, QuestionSubpart
    from openshiksha.apps.edge.models import Tick

    try:
        submission = Submission.objects.select_related(
            'assignment__problem_set',
            'assignment__subject_room',
            'student'
        ).get(pk=submission_id)
    except Submission.DoesNotExist:
        logger.error(f"Submission {submission_id} not found")
        return {'error': 'Submission not found'}

    answers = submission.answers  # {str(subpart_id): answer_value}
    problem_set = submission.assignment.problem_set
    subject_room = submission.assignment.subject_room

    # Load all subparts for the problem set's questions
    question_ids = problem_set.questions.values_list('id', flat=True)
    subparts = QuestionSubpart.objects.filter(
        question__in=question_ids
    ).select_related('question').prefetch_related('tags')

    total_subparts = subparts.count()
    attempted = 0
    total_mark = 0.0
    ticks_to_create = []

    for subpart in subparts:
        answer_key = str(subpart.id)
        if answer_key not in answers:
            continue

        attempted += 1
        student_answer = answers[answer_key]
        correct = subpart.correct_answer

        # Grade: simple equality check for MCQ/numeric; extend for other types
        mark = _grade_subpart(subpart.question.question_type, student_answer, correct)
        total_mark += mark

        ticks_to_create.append(Tick(
            student=submission.student,
            question_subpart=subpart,
            submission=submission,
            subject_room=subject_room,
            mark=mark,
        ))

    # Bulk create ticks
    Tick.objects.bulk_create(ticks_to_create)

    # Update submission
    submission.score = total_mark / total_subparts if total_subparts > 0 else 0.0
    submission.completion = attempted / total_subparts if total_subparts > 0 else 0.0
    submission.save(update_fields=['score', 'completion'])

    # Update assignment aggregates
    _update_assignment_aggregates.delay(submission.assignment_id)

    # Queue proficiency update
    update_proficiency.delay(submission.student_id, subject_room.id)

    return {
        'submission_id': submission_id,
        'total_subparts': total_subparts,
        'attempted': attempted,
        'score': submission.score,
        'completion': submission.completion,
        'ticks_created': len(ticks_to_create),
    }


def _grade_subpart(question_type: str, student_answer, correct_answer: dict) -> float:
    """
    Grade a single subpart answer. Returns a fraction (0.0 or 1.0 for exact match types).
    """
    if not correct_answer or 'answer' not in correct_answer:
        return 0.0

    expected = correct_answer['answer']

    if question_type in ('mcq', 'fill_blank', 'numeric', 'multi_select'):
        if question_type == 'numeric':
            # Allow floating point comparison with tolerance
            try:
                return 1.0 if abs(float(student_answer) - float(expected)) < 0.001 else 0.0
            except (TypeError, ValueError):
                return 0.0
        return 1.0 if str(student_answer) == str(expected) else 0.0

    # matching: partial credit — each correct pair = 1/n
    if question_type == 'matching':
        if not isinstance(expected, dict) or not isinstance(student_answer, dict):
            return 0.0
        correct_pairs = sum(
            1 for k, v in expected.items()
            if str(student_answer.get(k)) == str(v)
        )
        return correct_pairs / len(expected) if expected else 0.0

    return 0.0


@shared_task
def _update_assignment_aggregates(assignment_id: int) -> None:
    """Recompute assignment average_score and completion_rate from all submissions."""
    from openshiksha.apps.core.models import Assignment, Submission
    from django.db.models import Avg

    agg = Submission.objects.filter(
        assignment_id=assignment_id,
        submitted_at__isnull=False
    ).aggregate(
        avg_score=Avg('score'),
        avg_completion=Avg('completion')
    )
    Assignment.objects.filter(pk=assignment_id).update(
        average_score=agg['avg_score'] or 0.0,
        completion_rate=agg['avg_completion'] or 0.0
    )


@shared_task
def update_proficiency(student_id: int, subject_room_id: int) -> None:
    """
    Recalculate StudentProficiency for all tags from unacknowledged ticks.

    Steps:
    1. Load unacknowledged ticks for this student/subjectroom
    2. For each tick, update StudentProficiency for all tags on the subpart's question
    3. Mark ticks as acknowledged
    4. Recalculate percentile across all students in the SubjectRoom
    5. Update SubjectRoomProficiency
    """
    from openshiksha.apps.edge.models import Tick, StudentProficiency, SubjectRoomProficiency
    from django.db.models import Avg

    ticks = Tick.objects.filter(
        student_id=student_id,
        subject_room_id=subject_room_id,
        is_acknowledged=False
    ).select_related('question_subpart__question').prefetch_related(
        'question_subpart__tags',
        'question_subpart__question__tags'
    )

    if not ticks.exists():
        return

    for tick in ticks:
        # Tags from both the subpart and the question (union)
        all_tags = set(tick.question_subpart.tags.all()) | set(
            tick.question_subpart.question.tags.all()
        )
        for tag in all_tags:
            prof, _ = StudentProficiency.objects.get_or_create(
                student_id=student_id,
                question_tag=tag,
                subject_room_id=subject_room_id
            )
            prof.apply_tick(tick)

    # Acknowledge ticks
    ticks.update(is_acknowledged=True)

    # Recalculate percentiles for affected tags
    affected_tag_ids = StudentProficiency.objects.filter(
        student_id=student_id,
        subject_room_id=subject_room_id
    ).values_list('question_tag_id', flat=True)

    for tag_id in affected_tag_ids:
        _recalculate_percentile(subject_room_id, tag_id)


def _recalculate_percentile(subject_room_id: int, tag_id: int) -> None:
    """Recalculate percentile ranking for all students in a SubjectRoom for a tag."""
    from openshiksha.apps.edge.models import StudentProficiency, SubjectRoomProficiency

    profs = list(StudentProficiency.objects.filter(
        subject_room_id=subject_room_id,
        question_tag_id=tag_id
    ).order_by('rate'))

    if not profs:
        return

    n = len(profs)
    for i, prof in enumerate(profs):
        percentile = i / n  # fraction rank
        prof.recalculate_score(percentile)

    # Update SubjectRoom aggregate
    from django.db.models import Avg
    avg = StudentProficiency.objects.filter(
        subject_room_id=subject_room_id,
        question_tag_id=tag_id
    ).aggregate(avg_rate=Avg('rate'), avg_score=Avg('score'))

    SubjectRoomProficiency.objects.update_or_create(
        subject_room_id=subject_room_id,
        question_tag_id=tag_id,
        defaults={
            'rate': avg['avg_rate'] or 0.0,
            'score': avg['avg_score'] or 0.0,
        }
    )
```

## F. Legacy Analysis & Improvement Opportunities

### Tick Model
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Granularity | FK to `Question` (not subpart) | FK to `QuestionSubpart` — enables per-subpart proficiency tracking |
| Traceability | No reference back to submission | `submission` FK — allows auditing which answers produced which ticks |
| Decay | No timestamp | `created_at` — enables time-decay weighting in future algorithm improvements |

### StudentProficiency
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Save efficiency | Full `save()` on every tick | `update_fields` — avoids overwriting unrelated columns under concurrent updates |
| Clock | No `updated_at` | `updated_at` — enables cache invalidation and freshness checks |
| Field naming | `questiontag`, `subjectRoom` (camelCase) | `question_tag`, `subject_room` (snake_case PEP8) |

### Proficiency Algorithm
| Aspect | Legacy | Modern |
|--------|--------|--------|
| Formula | `(0.7 × rate) + (0.3 × percentile)` | Same formula — it's sound |
| Percentile calculation | Computed on demand | Compute async via Celery, store result |
| Future improvement opportunity | No time decay — old answers count equally | Could add exponential decay: recent ticks weighted more heavily |

### Grading
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Answer storage | Answers lived in Cabinet only | Answers in `Submission.answers` JSONField — grades without external service |
| Grading trigger | Unclear (separate Cabinet service) | `post_save` signal → Celery task — fully async, retryable |
| Partial credit | All-or-nothing per subpart | `matching` type: fractional partial credit per matched pair |
