## B. Why This Matters

Croupier Phase 2 is the last missing anti-cheating mechanism. Every student in every classroom currently sees identical numeric and fill-blank questions. Variable substitution means that `{{a}}x + {{b}} = {{c}}` renders as `"Solve 3x + 7 = 25"` for one student and `"Solve 6x + 14 = 44"` for another — uniquely seeded per student, reproducibly derived at grading time. Teachers in India depend on this for meaningful homework; it was the most-loved feature of the legacy Croupier.

The backlog behind the other two items (question-mistake analytics, learning path page) is zero new backend data work — both APIs are already live and populated. They are frontend-only tasks that can follow immediately once Phase 2 ships. Completing Phase 2 first also adds a concrete test touchstone: demo data will include a variable question, and end-to-end grading tests become more realistic.

```python
# ── Phase 2: Variable Substitution ────────────────────────────────────────────


def _make_var_seed(student_id: int, subpart_id: int) -> int:
    """Distinct seed namespace for variable substitution (Phase 2)."""
    seed_str = f"{student_id}:{subpart_id}:vars"
    return int(hashlib.sha256(seed_str.encode()).hexdigest(), 16) % (2**32)


def sample_variable_values(
    variable_constraints: dict,
    student_id: int,
    subpart_id: int,
) -> dict:
    """
    Sample variable values deterministically for a (student, subpart) pair.

    Returns {"a": 3, "b": 14} for the given constraints.
    Same inputs always produce the same output (reproducible at grading time).
    """
    seed = _make_var_seed(student_id, subpart_id)
    rng = random.Random(seed)
    values = {}
    for name, spec in variable_constraints.items():
        lo, hi = spec["min"], spec["max"]
        is_int = spec.get("integer", True)
        decimals = spec.get("decimals", 2)
        if is_int:
            values[name] = rng.randint(int(lo), int(hi))
        else:
            raw = rng.uniform(float(lo), float(hi))
            values[name] = round(raw, decimals)
    return values


def substitute_variables(text: str, variable_values: dict) -> str:
    """Replace {{var}} tokens in text with their sampled values."""
    for name, val in variable_values.items():
        text = text.replace(f"{{{{{name}}}}}", str(val))
    return text


def substitute_variables_for_student(
    question_text: str,
    options: "list[dict] | None",
    variable_constraints: "dict | None",
    student_id: int,
    subpart_id: int,
) -> "tuple[str, list[dict] | None, dict]":
    """
    Apply variable substitution to question_text and options for a student.

    Returns (substituted_text, substituted_options, variable_values).
    variable_values must be passed to the grader to evaluate correct_answer expressions.
    If variable_constraints is None or empty, returns inputs unchanged.
    """
    if not variable_constraints:
        return question_text, options, {}

    variable_values = sample_variable_values(variable_constraints, student_id, subpart_id)
    subst_text = substitute_variables(question_text, variable_values)
    subst_options = None
    if options:
        subst_options = [
            {"key": opt["key"], "text": substitute_variables(opt["text"], variable_values)}
            for opt in options
        ]
    return subst_text, subst_options, variable_values


# ── Safe expression evaluator (for correct_answer evaluation at grading time) ──

import ast
import operator as _op

_SAFE_OPS = {
    ast.Add: _op.add,
    ast.Sub: _op.sub,
    ast.Mult: _op.mul,
    ast.Div: _op.truediv,
    ast.Pow: _op.pow,
    ast.USub: _op.neg,
    ast.UAdd: _op.pos,
}


def _eval_ast_node(node):
    if isinstance(node, ast.Constant) and isinstance(node.value, (int, float)):
        return node.value
    if isinstance(node, ast.BinOp) and type(node.op) in _SAFE_OPS:
        return _SAFE_OPS[type(node.op)](_eval_ast_node(node.left), _eval_ast_node(node.right))
    if isinstance(node, ast.UnaryOp) and type(node.op) in _SAFE_OPS:
        return _SAFE_OPS[type(node.op)](_eval_ast_node(node.operand))
    raise ValueError(f"Unsafe or unsupported expression node: {type(node).__name__}")


def safe_eval_expr(expr: str, variable_values: dict) -> float:
    """
    Safely evaluate an arithmetic expression string with variable substitution.

    e.g. safe_eval_expr("({{c}} - {{b}}) / {{a}}", {"a": 3, "b": 5, "c": 20}) → 5.0

    Uses ast.parse — does NOT use eval(). Only supports +, -, *, /, **, unary -.
    Raises ValueError for unsupported operations or malformed expressions.
    """
    interpolated = substitute_variables(expr, variable_values)
    tree = ast.parse(interpolated, mode="eval")
    return float(_eval_ast_node(tree.body))
```

Note: The `import ast` and `import operator` should be moved to the top of the file with the other imports (`import hashlib`, `import random`) for style consistency. Move them before the existing imports.

```python
def to_representation(self, instance):
    data = super().to_representation(instance)
    request = self.context.get("request")
    if (
        request
        and hasattr(request, "user")
        and request.user.is_authenticated
        and instance.variable_constraints
    ):
        from openshiksha.apps.api.croupier import substitute_variables_for_student
        subst_text, subst_options, _ = substitute_variables_for_student(
            data["question_text"],
            data.get("options"),
            instance.variable_constraints,
            request.user.pk,
            instance.pk,
        )
        data["question_text"] = subst_text
        if subst_options is not None:
            data["options"] = subst_options
    return data
```

## F. Legacy Analysis — What Changes with Phase 2

### Croupier Phase 2 vs Legacy

**Legacy implementation (for reference only)**:
- `croupier/` fetched variable constraints from Cabinet (external service)
- Used raw Python `eval()` on teacher-authored answer expressions — security risk
- No authoring preview; teachers couldn't see what students would see
- Variable definitions tightly coupled to Cabinet CMS format

**Modern improvements shipped today**:
- `variable_constraints` stored in Django DB (JSONField on `QuestionSubpart`) — no external service, fully seedable, fully testable
- `safe_eval_expr` uses `ast.parse` + AST node whitelist — zero eval() risk, only arithmetic operators accepted
- Deterministic PRNG seeding per `(student_id, subpart_id)` — same student always sees same values (no session state needed)
- Distinct seed namespaces for Phase 1 (MCQ shuffle) and Phase 2 (variable substitution) — both can apply to the same subpart without interference
- Variable constraints auto-detectable from `{{var}}` tokens (for future authoring UI improvements)
