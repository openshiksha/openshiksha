## F. Legacy Analysis & Improvement Opportunities

### Frontend (Net New — Legacy had Django templates)

The legacy OpenShiksha frontend was server-rendered Django templates using Bootstrap 3. There was no React or TypeScript. The modern React frontend is entirely new design territory.

**What to borrow conceptually from legacy:**
- Dashboard design pattern: assignments grouped by due status (legacy had "today", "upcoming", "overdue" sections in the template)
- Progress indicators per subject/chapter (legacy had colored progress bars using the proficiency score)
- Subject color coding (legacy assigned a color to each subject — a nice touch for scannability)

**What to improve:**
- Legacy templates were desktop-only; modern version should be mobile-first
- Legacy had no loading states or optimistic updates; React Query gives us both
- Legacy assignments showed a list of question thumbnails (Cabinet images) — modern version can show content summary instead, as Cabinet integration is still pending

### Authentication
| Aspect | Legacy | Modern |
|--------|--------|--------|
| Auth mechanism | Django sessions (cookie) | JWT (access + refresh tokens) |
| Login form | Django template with CSRF | React form with API call |
| Token storage | Server-side session | localStorage (MVP); httpOnly cookie later |
| Role routing | Server-side redirect | Client-side redirect based on JWT role claim |
