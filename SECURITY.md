# Security Policy

## Supported versions

OpenShiksha is deployed continuously from the `qa` release branch. Only the
**currently deployed version** (the tip of `qa` / what runs at
[openshiksha.org](https://openshiksha.org)) is supported with security fixes.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, report privately via one of:

- GitHub's [private vulnerability reporting](https://github.com/openshiksha/openshiksha/security/advisories/new)
  (Security tab → "Report a vulnerability"), or
- email **security@openshiksha.org**.

Please include:

- a description of the issue and its impact,
- steps to reproduce (or a proof of concept),
- any suggested remediation.

We aim to acknowledge reports within a few days and will keep you updated on
progress. Once a fix ships, we're happy to credit you (unless you prefer to
remain anonymous).

Thank you for helping keep OpenShiksha and its students safe.
