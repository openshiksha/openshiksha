# OpenShiksha Daily Plan — 2026-03-27

## A. Today's Objective

Build the **Question Bank + SubjectRoom + Assignment + Submission models** — the complete core educational data layer that unlocks the teacher-assigns → student-practices → system-grades workflow.

---

## B. Why This Matters

Phase 0 and Phase 1 gave us the structural scaffolding: users, schools, classrooms. But without questions and assignments, the platform does nothing educational. Today's work closes the gap between "infrastructure exists" and "the platform can actually teach." It unblocks:

- **All student-facing features** — students need assignments to do anything
- **All teacher-facing features** — teachers need to create/assign problem sets
- **Analytics** — Tick and Proficiency models depend on Submissions
- **The API layer** — ViewSets have nothing to serve until models exist

Legacy had this working, but with design choices that reflected Django 1.x era constraints (Python 2, no type hints, GenericFK overuse, flat Chapter model without Standard FK). Today's models improve on all of these.

**`Question`**
```python
class QuestionType(models.TextChoices):
    MCQ = 'mcq', 'Multiple Choice'
    FILL_BLANK = 'fill_blank', 'Fill in the Blank'
    MATCHING = 'matching', 'Matching'
    MULTI_SELECT = 'multi_select', 'Multi Select'
    NUMERIC = 'numeric', 'Numeric Answer'

class Question(models.Model):
    school = models.ForeignKey('School', on_delete=models.CASCADE, null=True, blank=True,
        help_text='null = OpenShiksha shared bank')
    standard = models.ForeignKey('Standard', on_delete=models.PROTECT)
    subject = models.ForeignKey('Subject', on_delete=models.PROTECT)
    chapter = models.ForeignKey('Chapter', on_delete=models.PROTECT)
    tags = models.ManyToManyField(QuestionTag, blank=True)
    question_type = models.CharField(max_length=20, choices=QuestionType.choices, default=QuestionType.MCQ)
    difficulty = models.PositiveSmallIntegerField(default=2, validators=[MinValueValidator(1), MaxValueValidator(5)])
    is_active = models.BooleanField(default=True)
    created_by = models.ForeignKey('User', on_delete=models.SET_NULL, null=True, blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
```
- **Legacy kept**: school FK (null = shared bank), standard/subject/chapter FK, tags M2M
- **Improved**: `question_type` (MCQ was the only type in legacy), `difficulty` 1-5 scale (legacy derived this from tags only), `is_active` for soft delete, `created_by` for audit trail, `updated_at` for cache busting

**`QuestionSubpart`**
```python
class QuestionSubpart(models.Model):
    question = models.ForeignKey(Question, on_delete=models.CASCADE, related_name='subparts')
    index = models.PositiveIntegerField()
    tags = models.ManyToManyField(QuestionTag, blank=True)
    correct_answer = models.JSONField(default=dict,
        help_text='Flexible answer storage: {type: mcq, answer: 2} or {type: fill_blank, answer: "42"}')

    class Meta:
        ordering = ['index']
        unique_together = [['question', 'index']]
```
- **Legacy kept**: question FK, index, tags
- **Improved**: `correct_answer` as JSONField — legacy had no answer storage in DB (it lived in Cabinet), modern design stores answer here for fast grading fallback

**`SubjectRoom`**
```python
class SubjectRoom(models.Model):
    classroom = models.ForeignKey('ClassRoom', on_delete=models.CASCADE, related_name='subject_rooms')
    subject = models.ForeignKey('Subject', on_delete=models.PROTECT, related_name='subject_rooms')
    teacher = models.ForeignKey('User', on_delete=models.PROTECT,
        related_name='subject_rooms_taught',
        limit_choices_to={'role': UserRole.TEACHER})
    students = models.ManyToManyField('User', related_name='subject_rooms_enrolled', blank=True,
        limit_choices_to={'role__in': [UserRole.STUDENT, UserRole.OPEN_STUDENT]})
    is_active = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        unique_together = [['classroom', 'subject']]
        indexes = [models.Index(fields=['classroom', 'is_active'])]
```
- **Legacy kept**: classroom, subject, teacher, students M2M
- **Improved**: `is_active` for year-end archiving; `unique_together` on (classroom, subject) enforces one SubjectRoom per subject per class

```python
class ProblemSet(models.Model):
    """Curated list of questions that can be assigned. Replaces legacy AssignmentQuestionsList."""
    school = models.ForeignKey('School', on_delete=models.CASCADE, null=True, blank=True,
        help_text='null = shared OpenShiksha problem set')
    standard = models.ForeignKey('Standard', on_delete=models.PROTECT)
    subject = models.ForeignKey('Subject', on_delete=models.PROTECT)
    chapter = models.ForeignKey('Chapter', on_delete=models.PROTECT)
    questions = models.ManyToManyField(Question, related_name='problem_sets')
    title = models.CharField(max_length=255)
    description = models.TextField(blank=True)
    number = models.PositiveIntegerField(default=1, help_text='Series number within same chapter')
    estimated_minutes = models.PositiveIntegerField(null=True, blank=True,
        help_text='Estimated time to complete in minutes')
    is_active = models.BooleanField(default=True)
    created_by = models.ForeignKey('User', on_delete=models.SET_NULL, null=True, blank=True)
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        unique_together = [['school', 'standard', 'subject', 'chapter', 'number']]
```
- **Legacy kept**: school/standard/subject/chapter FK, questions M2M, number (series disambiguator), description
- **Improved**: `title` as explicit field (legacy computed it), `estimated_minutes` (new — teachers can tell students how long it should take), `is_active` soft delete, `created_by` audit

**`Assignment`**
```python
class Assignment(models.Model):
    subject_room = models.ForeignKey('SubjectRoom', on_delete=models.CASCADE, related_name='assignments')
    problem_set = models.ForeignKey(ProblemSet, on_delete=models.PROTECT, related_name='assignments')
    assigned_by = models.ForeignKey('User', on_delete=models.PROTECT, related_name='assignments_created')
    assigned_at = models.DateTimeField(auto_now_add=True)
    due_at = models.DateTimeField()
    # Computed aggregates (cached after grading)
    average_score = models.FloatField(null=True, blank=True, validators=FRACTION_VALIDATOR)
    completion_rate = models.FloatField(null=True, blank=True, validators=FRACTION_VALIDATOR)
    number = models.PositiveIntegerField(default=1, help_text='Disambiguates same problem set assigned twice')

    class Meta:
        indexes = [
            models.Index(fields=['subject_room', 'due_at']),
            models.Index(fields=['assigned_at']),
        ]
```
- **Legacy kept**: assignment questions list FK, assigned/due timestamps, average/completion cached aggregates, number
- **Improved**: Direct `subject_room` FK instead of GenericFK (GenericFK caused N+1 query issues and made filtering impossible); `assigned_by` for accountability; `assigned_at` auto_now_add instead of manual timestamp

**`Submission`**
```python
class Submission(models.Model):
    assignment = models.ForeignKey(Assignment, on_delete=models.CASCADE, related_name='submissions')
    student = models.ForeignKey('User', on_delete=models.PROTECT, related_name='submissions',
        limit_choices_to={'role__in': [UserRole.STUDENT, UserRole.OPEN_STUDENT]})
    score = models.FloatField(null=True, blank=True, validators=FRACTION_VALIDATOR,
        help_text='Fraction of marks obtained')
    completion = models.FloatField(default=0.0, validators=FRACTION_VALIDATOR,
        help_text='Fraction of questions attempted')
    submitted_at = models.DateTimeField(null=True, blank=True)
    is_revised = models.BooleanField(default=False)
    answers = models.JSONField(default=dict,
        help_text='Student answers: {subpart_id: answer_value}')
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        unique_together = [['assignment', 'student']]
        indexes = [models.Index(fields=['student', 'submitted_at'])]
```
- **Legacy kept**: assignment FK, student FK, marks/score fraction, completion fraction, revised flag, timestamp
- **Improved**: `answers` JSONField (legacy stored answers only in Cabinet; storing here enables fast re-grading and offline review), `submitted_at` nullable (submission exists before it's submitted — student in-progress state), `created_at`/`updated_at` for tracking when student started

```python
class IsTeacher(BasePermission):
    def has_permission(self, request, view):
        return request.user.role == UserRole.TEACHER

class SubjectRoomViewSet(ModelViewSet):
    queryset = SubjectRoom.objects.select_related('classroom', 'subject', 'teacher')
```

## F. Legacy Analysis & Improvement Opportunities

### Question Model
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Question types | MCQ only (enforced by Cabinet) | `question_type` enum — MCQ, fill_blank, matching, etc. |
| Difficulty | Derived from tags (hacky) | Explicit `difficulty` 1-5 field |
| Soft delete | Hard delete or never deleted | `is_active` flag |
| Chapter granularity | Chapter had no Standard FK — ambiguous | Chapter has Standard FK (already done in Phase 1) |
| Answer storage | Only in Cabinet (external service) | `correct_answer` JSONField in QuestionSubpart — enables offline grading |

### Assignment Model
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Target (who gets assigned) | GenericFK to SubjectRoom OR Remedial OR User | Direct `subject_room` FK — simpler, faster, filterable |
| Practice assignments (OpenStudents) | Special case via GenericFK to User | Handle via `open_student_assignments` separate endpoint |
| Naming | `AssignmentQuestionsList` | `ProblemSet` — cleaner, more intuitive |
| Time estimate | None | `estimated_minutes` on ProblemSet |

### Submission Model
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Answer storage | In Cabinet only | `answers` JSONField — enables re-grading without Cabinet |
| In-progress state | No — submit was all-or-nothing | `submitted_at` nullable — student can save progress |
| Marks naming | `marks` (confusing fraction vs points) | `score` (clearer it's a fraction 0-1) |

### SubjectRoom Model
| Aspect | Legacy | Modern improvement |
|--------|--------|--------------------|
| Uniqueness | No unique_together | `unique_together = [classroom, subject]` |
| Archive | No `is_active` | `is_active` for year-end archiving without deletion |
