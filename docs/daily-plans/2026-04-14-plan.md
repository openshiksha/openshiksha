from openshiksha.apps.edge.models import SubjectRoomQuestionMistake  # add to imports
from openshiksha.apps.api.serializers.core import QuestionMistakeSerializer  # add to imports

class QuestionMistakeViewSet(viewsets.ReadOnlyModelViewSet):
    """
    GET /api/question-mistakes/?subject_room=<id>
    Returns questions ordered by regression (hardest first).
    Restricted to teachers; only returns data for their own subject rooms.
    """
    serializer_class = QuestionMistakeSerializer
    permission_classes = [permissions.IsAuthenticated, IsTeacher]

    def get_queryset(self):
        qs = (
            SubjectRoomQuestionMistake.objects.filter(
                subject_room__teacher=self.request.user
            )
            .select_related("question", "subject_room")
            .prefetch_related("question__subparts")
            .order_by("-regression")
        )
        subject_room_id = self.request.query_params.get("subject_room")
        if subject_room_id:
            qs = qs.filter(subject_room_id=subject_room_id)
        return qs
```

Key design decisions:

const PathCard = ({ path }: { path: LearningPath }) => {
  const progressPct = Math.round(path.progress_pct * 100);
  const sorted = [...path.steps].sort((a, b) => a.position - b.position);
  const currentIndex = sorted.findIndex((s) => s.status === 'in_progress') ??
    sorted.findIndex((s) => s.status === 'not_started');

  return (
    <div className="bg-white rounded-xl border border-gray-200 p-5">
      <div className="flex items-center justify-between mb-2">
        <h3 className="text-sm font-semibold text-gray-900">{path.status_display}</h3>

        <div
          className="h-full bg-indigo-500 rounded-full transition-all"
          style={{ width: `${progressPct}%` }}
        />
      </div>
      <div>
        {sorted.map((step, i) => (
          <StepRow key={step.id} step={step} isCurrent={i === currentIndex} />
        ))}
      </div>
    </div>
  );

const extractTokens = (text: string): string[] => {
  const re = /\{\{(\w+)\}\}/g;
  const names = new Set<string>();
  let match: RegExpExecArray | null;
  while ((match = re.exec(text)) !== null) names.add(match[1]);
  return Array.from(names).sort();
};
```

#### Step 5 — Live preview widget

```tsx
const xorshift32 = (seed: number) => {
  let s = seed | 1;
  return () => {
    s ^= s << 13; s ^= s >> 17; s ^= s << 5;
    return (s >>> 0) / 4294967296;
  };
};

const sampleValues = (
  constraints: Record<string, { min: number; max: number; integer: boolean }>,
  studentNum: number
): Record<string, number> => {
  const rng = xorshift32(studentNum * 31337);
  const out: Record<string, number> = {};
  for (const [name, spec] of Object.entries(constraints)) {
    const raw = rng() * (spec.max - spec.min) + spec.min;
    out[name] = spec.integer ? Math.round(raw) : parseFloat(raw.toFixed(2));
  }
  return out;
};

const substituteText = (text: string, values: Record<string, number>): string =>
  text.replace(/\{\{(\w+)\}\}/g, (_, name) =>
    values[name] !== undefined ? String(values[name]) : `{{${name}}}`
  );

const VariablePreview = ({
  constraints,
  questionText,
}: {
  constraints: Record<string, { min: number; max: number; integer: boolean }>;
  questionText: string;
}) => {
  if (!Object.keys(constraints).length) return null;
  const v1 = sampleValues(constraints, 1);
  const v2 = sampleValues(constraints, 2);
  return (
    <div className="mt-3 pt-3 border-t border-amber-200">
      <p className="text-xs font-semibold text-amber-900 mb-1">Preview</p>
      <p className="text-xs text-gray-600">Student A: {substituteText(questionText, v1)}</p>
      <p className="text-xs text-gray-600 mt-0.5">Student B: {substituteText(questionText, v2)}</p>
    </div>
  );
};
```

## F. Legacy Analysis & Improvement Opportunities

### Teacher Analytics (Priority 1)

**Legacy**: No per-question difficulty analytics existed. Teachers saw aggregate assignment scores and raw submission counts — nothing at the question level. The closest thing was the grader's per-subpart `Tick` record, which was never surfaced to teachers.

**Modern improvement**: `SubjectRoomQuestionMistake.regression` is the *cumulative marks lost* per question per subject room — a weighted signal that accounts for question value, not just "answered wrong N times." The "Hardest Questions" panel surfaces this directly. Future improvement: add `mistake_rate = regression / (total_submissions * max_score)` to normalize across classes of different sizes.

### Learning Path (Priority 2)

**Legacy**: No learning path. Students received whatever assignments teachers manually assigned. No adaptive sequencing, no spaced repetition, no gap identification.

**Modern improvement**: The AI engine builds `LearningPath` + `LearningPathStep` records from `StudentMastery` gaps, using `KnowledgeNode` dependencies for step ordering. `SpacedRepetitionEntry` marks steps for review when they decay (SM-2). Surfacing this to students gives them agency over their own learning sequence — something the legacy system never had.

### Variable Constraints Authoring (Priority 3)

**Legacy**: Variable definitions were stored in Cabinet (external HTTP service) JSON. No in-app authoring UI existed. Teachers who wanted variable questions had to edit Cabinet records directly, which was brittle and required technical access.

**Modern improvement**: Variables live in `QuestionSubpart.variable_constraints` (JSONField, in-DB). Auto-detection of `{{var}}` tokens from `question_text`, in-form editing of ranges, and a live preview reduce teacher authoring errors before questions reach students.
